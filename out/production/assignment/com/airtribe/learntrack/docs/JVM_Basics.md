

JVM Basics
1) JDK, JRE, and JVM
   JDK (Java Development Kit)
   JDK is used to develop Java programs.
   It includes:

the Java compiler (javac)
debugging/development tools
JRE (Java Runtime Environment)
So, if you want to write + compile + run Java code, you install JDK.

JRE (Java Runtime Environment)
JRE is used to run Java programs.
It includes:

JVM
core runtime libraries (like java.lang, java.util, etc.)
JRE does not include development tools like javac, so it cannot compile source code by itself.

JVM (Java Virtual Machine)
JVM is the engine that actually executes Java bytecode.
It is platform-specific in implementation (Windows JVM, Linux JVM, etc.), but all follow the same Java standard.
That is why the same .class file can run on different operating systems if a compatible JVM is installed.

2) What is Bytecode?
   When we write Java code in a .java file, the compiler (javac) converts it into bytecode (.class file).
   Bytecode is not direct machine code for one CPU. It is an intermediate format that the JVM understands and executes.

3) What does “Write Once, Run Anywhere” mean?
   “Write Once, Run Anywhere” means you write and compile Java code once, and the generated bytecode can run on any operating system that has a compatible JVM.
   For example, a .class file compiled on Windows can run on Linux or macOS without rewriting the program.

This works because Java code runs on the JVM, and JVM implementations are available for multiple platforms.
