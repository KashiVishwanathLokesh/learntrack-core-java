Core Entities:
1. BookEntity; represents a book in library with attributes like title author, YOP, ISBN.
2. Patron: represents a library user with attributes like name, email and id.
3. Library management: contains all the logic to add update and remove books and patron.
4. implemented stragtegy design pattern to implement different search strategies for books and patrons.
5. implemented builder design pattern to create complex book and patron objects.
6. notify user: implemented observer design pattern to notify users about new books and events in the library.
